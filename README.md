# Richard Barát — realitní makléř

Samostatný web Richarda Baráta, CENTURY 21 All Inclusive.

## Vývoj
- Node.js 22+
- `npm install`
- `npm run dev`
- `npm run build`

Framework: TanStack Start (React 19), Vite, Tailwind CSS v4.

Cloudflare Pages: build command `npm run build`, output directory `.output/public`.

### Důležité
- Jde o první návrh webu, ne hotové produkční řešení.
- Vícekrokový odhad ceny nemovitosti zatím **neodesílá poptávky**; serverovou integraci a antispam je třeba teprve vytvořit.
- Fotografie nemovitostí jsou ilustrativní a zatím jsou načítány z Macaly Assets CDN.
- Odkazy na nabídku a realizace zatím vedou na obecný katalog CENTURY 21; je třeba doplnit přímé Richardovy odkazy.
- Richardův portrét nebyl z původního Macaly projektu dosud přenesen; je potřeba ho vložit do webu.

Při úpravách se **nesmí měnit** repozitáře Milan Juřena ani vittorio-reality.cz.
